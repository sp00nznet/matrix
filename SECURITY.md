# Security

This is a hobby research project with no production deployment.

- **Reporting:** open a private security advisory on this repository (Security tab →
  Report a vulnerability). Please don't file public issues for vulnerabilities.
- **Credentials:** `MXO_LOGIN=user:password` passes a login for your own local test server
  on the command line and environment. Don't use a password you use anywhere else.
- **Running the client:** the host maps and executes a game binary you supply, and makes
  its pages non-executable to catch calls into it. Only run it on game files you trust.
